## tryParseJson()
Parses a JSON string, returning the input untouched when it is not a string
or is not valid JSON.

### Examples

```ts twoslash
import { tryParseJson } from 'seitu/utils'

tryParseJson('{"a":1}') // { a: 1 }
tryParseJson('oops') // 'oops'
tryParseJson(42) // 42
```
