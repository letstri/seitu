## createStore()

```ts twoslash
import { createStore } from 'seitu'

const store = createStore({ count: 0 })
store.set(prev => ({ ...prev, count: prev.count + 1 }))
store.subscribe(state => console.log(state))
store.get() // { count: 1 }
```
